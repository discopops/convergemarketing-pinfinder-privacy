PinFinder Studio — Privacy Policy

Effective: 12 October 2026

PinFinder Studio is a locally run, personal-use application for discovering Pinterest Pins and saving inspiration. It is an independent project and is not affiliated with, endorsed by, or operated by Pinterest.

Information used

The application processes the search terms you enter. If you configure access to the Pinterest API, the local server sends search terms and a server-held Pinterest OAuth access token to Pinterest so it can retrieve matching Pins. The token is not sent to the application's browser interface. Pinterest processes API requests under its own privacy policies.

Saved Pins

When you save a Pin within the application, the Pin identifier, title, image URL, and link are kept in your browser's local storage on your device. These saved items are not sent to a third-party storage service by PinFinder Studio. You can remove saved items within the app or clear your browser site data.

Sharing and tracking

The app does not sell personal information, run behavioural advertising, or include an analytics tracker. Pinterest-hosted image previews are loaded directly from Pinterest image servers, which may receive standard browser request information such as your IP address. Clicking a Pin opens Pinterest in your browser.

Retention and security

Saved-Pin information remains in your browser until you delete it or clear local storage. API credentials are configured on the local server and should not be uploaded to public repositories. The app does not implement an online account or central user database.

Changes

This page will be updated if the application's data handling changes. The application's source code and local deployment determine the actual processing undertaken.

Questions

For questions about this personal-use application, please open an issue in the project's public GitHub repository. Do not include API keys or other personal secrets.
